# AI Usage

여러 AI 서비스의 사용량과 재설정 일정을 모바일에서 한눈에 확인할 수 있는 웹 대시보드입니다.

![AI Usage 모바일 화면](docs/ai-usage-mobile.png)

## 주요 기능

- Claude, Gemini, Antigravity, Codex, Copilot 서비스 전환 (**상단 네비게이션**)
- 서비스별 사용량 진행률과 다음 재설정 시각 표시
- **API 키/토큰을 저장하면 프록시 서버를 통해 실제 사용량 조회**
- 실시간/예시 데이터를 배지로 명확히 구분 표시
- 수동 새로고침 피드백 및 마지막 선택 서비스 저장
- 시스템 설정을 반영하는 라이트/다크 테마
- 모바일, 태블릿, 데스크톱에 대응하는 반응형 레이아웃

## 실제 사용량 조회하기

각 AI의 사용량 API는 **아이디/비밀번호가 아니라 API 키·토큰**으로 인증합니다.
또한 브라우저는 CORS 정책 때문에 공급자 API를 직접 호출할 수 없으므로,
브라우저 대신 API를 호출해 주는 작은 **프록시 서버**가 필요합니다.

1. 프록시 서버를 실행합니다 (Node.js 18+, 의존성 없음).

   ```bash
   node server/proxy.js          # 기본 http://localhost:8787
   ```

2. 정적 대시보드를 실행합니다.

   ```bash
   python3 -m http.server 4173 --directory docs
   ```

3. 브라우저에서 <http://localhost:4173>을 열고, 우측 상단 **⚙️ 설정**을 누릅니다.
4. **프록시 서버 주소**에 `http://localhost:8787`을 입력합니다.
5. 각 서비스의 API 키/토큰을 입력하고 **저장하고 조회**를 누릅니다.
   키는 이 브라우저의 `localStorage`에만 저장되며 서버에 남지 않습니다.

### 서비스별 필요한 자격 증명

| 서비스 | 입력 값 | 조회 내용 |
| --- | --- | --- |
| Claude | Anthropic **Admin API 키** (`sk-ant-admin…`) + 월 예산 | 이번 달 비용 대비 예산 사용률 |
| Codex (OpenAI) | OpenAI **API 키** (`sk-…`) + 조직 ID(선택) + 월 예산 | 이번 달 비용 대비 예산 사용률 |
| Copilot | GitHub **토큰(PAT)** + 조직/사용자명 | Copilot 좌석 사용 현황 |
| Gemini | Google **API 키** | 키 유효성 확인 (공개 사용률 API 미제공) |
| Antigravity | — | 공개 사용량 API가 없어 실시간 조회 미지원 |

> 키가 없거나 프록시에 연결할 수 없으면 예시 데이터가 표시되고, 카드에 **예시** 배지가 붙습니다.
> 실제 조회에 성공하면 **실시간** 배지로 바뀝니다.

## GitHub Pages 배포

`docs/` 폴더의 프런트엔드만으로도 배포할 수 있습니다. 다만 GitHub Pages는
정적 호스팅이라 프록시를 함께 실행할 수 없으므로, 배포본에서는 예시 데이터만
표시됩니다. 실제 조회가 필요하면 프록시(`server/proxy.js`)를 별도 호스트에
올리고 설정에서 그 주소를 입력하세요.

## 프로젝트 구조

```text
docs/
├── index.html   # 화면 구조와 접근성 마크업
├── styles.css   # 반응형 UI 및 테마
├── api.js       # 자격 증명 저장 · 사용량 조회 데이터 계층
└── app.js       # 화면 렌더링 및 상호작용
server/
└── proxy.js     # 각 공급자 사용량 API를 호출하는 프록시 (의존성 없음)
```
