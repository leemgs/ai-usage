Copilot 연결

1
프록시(어댑터) 실행 & 주소 입력

node server/proxy.js 를 실행한 주소를 입력하세요. 브라우저는 보안 정책(CORS)상 공급자 API를 직접 부를 수 없어 이 프록시가 대신 호출합니다.

2
공식 API 키/토큰 입력

🔒 키는 이 브라우저(localStorage)와 위 프록시로만 전송됩니다. 외부 서버로 보내지 않습니다. 되도록 읽기 전용·최소 권한 키를 사용하세요.

이미 Usage API 어댑터를 운영 중인가요?

아래 형식의 JSON을 반환하는 HTTPS 주소를 직접 연결할 수 있습니다.

응답 형식 보기
{
  "account": "my-account",
  "updatedAt": "2026-08-09T09:00:00Z",
  "resetAt": "2026-09-01T09:00:00+09:00",
  "metrics": [
    {"label": "프리미엄 요청", "used": 12, "limit": 300}
  ],
  "history": [           // 선택: 있으면 추이 그래프 표시
    {"date": "2026-08-01", "used": 8, "limit": 300}
  ]
}
